# ADHD — Eurorack video module v2

Рабочий проект второй версии DIY-модуля: видео с карты памяти,
переключение по триггеру и осциллограмма входного аудио поверх видео.
Новая цель — 60 FPS и плавный вывод без мерцания, композиция на GPU.
Сравниваются дешёвая сборка на компонентах и готовые узлы с минимумом пайки.
Zero 2 W и TFT v1 остаются испытательным кандидатом; Pi 4 и HDMI-экран —
более дорогой вариант. USB-A допустим для зарядки.

Резервная копия v1 и фотографии получены и изучены. Восстановлены подготовка
и воспроизведение RAW-видео; код обработки триггера, аудио и прошивка Arduino
в архиве не найдены. Документация v2 содержит предварительные предложения,
а не результаты испытаний готового модуля.

## Работа в облачной среде

Используйте существующий checkout `/workspace/adhd`: каждая облачная задача
уже изолирована, отдельный Git worktree не требуется.

Для анализа видео нужны Python 3, FFmpeg и FFprobe. Проверка выполняется
из корня проекта:

```sh
python tools/check_video_stack.py
python -m unittest discover -s tests -v
```

Первая команда генерирует синтетическое видео и аудио, накладывает осциллограмму,
проверяет 60 FPS и 120 разных декодированных кадров за 2 секунды. Вторая
проверяет новые компоненты импорта видео и обработки осциллограммы.
Это проверки инструментов и программных компонентов
облачной среды; скорость работы на целевой плате, живой аудиовход и
задержка переключения клипов должны проверяться отдельно на оборудовании.

## Новая программная основа

- `tools/import_media.py`: проверка файлов и атомарный импорт в отдельный
  кэш H.264. Сохраняет исходную частоту до 60 FPS и оригиналы; различает
  формат-кандидат и проверенную аппаратную совместимость. Это backend,
  не реализованный пользовательский процесс вставки карты.
- `tools/waveform_core.py`: ограниченный аудиобуфер, целостные снимки,
  min/max-огибающая и стабилизация по пересечению уровня. Без обращения
  к АЦП или framebuffer; GPU-рендер ещё предстоит подключить.
- [Проверки готового прототипа](docs/validation-60fps.md).

Для разработчика импорт папки выполняется так:

```sh
python tools/import_media.py /path/to/video-card --cache /path/to/internal-cache
```

Кэш должен находиться вне папки источников. В готовом модуле этот компонент
будет вызываться автоматически; пользователю не предполагается вводить команду.

Резервные копии можно хранить локально в игнорируемом каталоге `backups/`.
Перед публикацией файлов из старого архива нужно проверить, нет ли в нём
ключей, паролей, cookies загрузчика и личных материалов.
