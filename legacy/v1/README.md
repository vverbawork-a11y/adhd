# Сохранившиеся скрипты v1

Точные копии трёх пользовательских скриптов из `pi backup.zip`, без исправлений.
Это материалы для исследования и переноса поведения, а не настроенный запуск v2.

- `prepare_memes.sh`: MP4 → повёрнутый/обрезанный RGB565LE RAW 320×240, 30 FPS.
- `play_brainrot.sh`: выбор случайного файла и бесконечный цикл, BGR565LE, 60 FPS.
- `start_random_video.sh`: другой вариант запуска, RGB565LE без явного FPS.

Скрипты имеют несовместимые параметры; порядок их использования в рабочем
модуле неизвестен. Они обращаются к Raspberry Pi GPIO и `/dev/fb1`, которых
нет в облачной машине. Не использовать их как готовую инструкцию установки.

Полный оригинальный архив, фотографии и история команд сохранены локально
в игнорируемом `backups/v1/`. RAW-видео, SSH-файлы и история команд в Git
не добавлены. Результаты разбора — в `docs/v1-reconstruction.md`.
